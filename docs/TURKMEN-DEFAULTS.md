# Туркменский интерфейс

Основной язык сайта, кабинетов и Mini App — `tk` (Türkmençe). При первом посещении язык браузера не меняет его. Переключатель сохраняет явный выбор в cookie `NEXT_LOCALE_TM`; прежняя cookie `NEXT_LOCALE` не используется. Отсутствующие переводы берутся из туркменского словаря.

Старые логотипы не отображаются. Исходники сохранены в `public/brand/`, иконки приложения перенесены туда же с префиксом `archived-`. Место для будущего логотипа пустое.

Телефон: `+993` и восемь цифр национального номера. Принимаются также восемь цифр без кода и формат `00993…`. Номера другой страны и слишком длинные номера отклоняются, маска их не обрезает до валидного номера. Настоящий контакт необходимо указать в CRM; российский номер не заменяется выдуманным туркменским.

Новые цены и заказы — в манатах (`TMT`). Числовой прайс сохранён, конвертация по курсу не выполнялась. Миграция `0014_turkmen_defaults.sql` помечает существующие заказы как `RUB`; валюта существующих платежей сохраняется. Новые платежи наследуют валюту заказа. Проверка в БД запрещает платежи другой валюты и изменение валюты заказа. Сводные денежные показатели CRM считают только TMT; в историях показывается фактическая валюта. Экспорт сумм по заказам/платежам содержит отдельную колонку валюты.

Для TMT доступна тестовая оплата (`PAYMENT_PROVIDER=mock`) и учёт оплаты в точке. Интеграция ЮKassa ограничена RUB: запросы TMT отклоняются до обращения к провайдеру. Для реального онлайн-приёма манатов требуется отдельная интеграция с подходящим банком или провайдером.

После обновления: `pnpm db:push`, затем `pnpm dev`. Проверки: `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm build`, `pnpm test:sql` (нужен запущенный PostgreSQL/Supabase).
