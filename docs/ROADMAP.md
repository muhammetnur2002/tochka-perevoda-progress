# Дорожная карта

## Этап 1 — текущая версия ✅

Сайт и каталог (24 позиции), калькулятор со сроками по производственному
календарю, оформление с загрузкой и камерой, оплата СБП/QR/карта (ЮKassa + mock),
статус, личный кабинет, подтверждение телефона, Telegram-бот и Mini App с чатом,
CRM (канбан, карточка, клиенты, прайс, исполнители, финансы, отчёты, экспорт,
настройки, аудит), кабинет переводчика, уведомления с фолбэком и очередью
повторов, RLS-тесты, 152-ФЗ (согласия, выгрузка/удаление, хранение).

## Этап 2 — ИИ и автоматизация

- Определение языка, типа документа и числа страниц по загруженному файлу
  (OCR Yandex Vision + YandexGPT) → предзаполнение калькулятора. Интерфейс готов: `src/lib/ai`.
- Черновой машинный перевод для переводчика в `/workspace` (не для клиента).
- Ответы бота на типовые вопросы (FAQ, цены, сроки) с передачей менеджеру.
- Шифрование файлов AES-256-GCM на сервере (ключ в Lockbox/KMS), feature-flag.
- Промокоды и скидки постоянным клиентам (`orders.promo_code` уже в схеме).
- Счета и акты для юрлиц (PDF), онлайн-касса 54-ФЗ через ЮKassa (параметры заготовлены).

## Этап 3 — масштабирование

- PWA (офлайн-статус, push-уведомления), мобильное приложение.
- Мультиязычный интерфейс (англ., узб., тадж.) — next-intl.
- Несколько офисов/точек выдачи, график переводчиков, автоназначение по языку и загрузке.
- Интеграция с 1С/МойСклад, электронный документооборот.
- Отзывы и NPS после выдачи заказа.
