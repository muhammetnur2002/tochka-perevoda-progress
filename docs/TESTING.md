# Тестирование

| Уровень | Команда | Что проверяет |
|---|---|---|
| Типы | `pnpm typecheck` | TypeScript strict (+ `noUncheckedIndexedAccess`) по всему коду |
| Линт | `pnpm lint` | ESLint (next/core-web-vitals, next/typescript) |
| Unit | `pnpm test` | 54 теста: движок цен (срочность, объём, заверение, копейки), календарь МСК, Zod-схемы, подпись Telegram initData, IP-allowlist и разбор вебхука ЮKassa, токены гостя, матрица прав и переходы статусов, CSV-инъекции, шаблоны уведомлений, сверка прайса TS ↔ SQL (24 позиции) |
| SQL | `pnpm test:sql` | `rls_check.sql` (10 сценариев: повышение роли, видимость по ролям, запрет прямой вставки заказа, переводчик только по назначению, аудит, гость, привязка по подтверждённому телефону, триггеры оплаты/нагрузки) и `pricing_check.sql` (формула итога, 24 услуги) — в транзакции с ROLLBACK |
| E2E | `pnpm test:e2e` | публичные страницы, калькулятор, защита разделов; `E2E_FULL=1` — заказ гостем с mock-оплатой, статус, вход менеджера и канбан |
| Сборка | `pnpm build` | собирается без ключей и без обращения к БД (страницы с данными — dynamic) |

## SQL-тесты без Supabase

Миграции проверяются на обычном PostgreSQL 15+ с заглушками схем `auth`/`storage`:

```bash
# сервер Postgres, где у пользователя есть право CREATE DATABASE
DATABASE_URL=postgresql://postgres@127.0.0.1:5432/postgres pnpm test:sql -- --fresh
```
